Intro

This post describes my homelab setup so I can link it where needed (like in my resume). It changes all the time as I add things and break others, so this is how it looks as of November 2026. Most of the pieces below have their own post with the actual steps.

Hardware

Everything runs on a single Dell PowerEdge T440 with Proxmox VE 9.

Dell PowerEdge T440

  • 2x Xeon Gold 6126 (24 cores, 48 threads)
  • 256GB ECC RAM
  • Intel X540-T2 dual port 10GbE
  • PNY GeForce RTX 5060 8GB
  • 2x 1.92TB Samsung PM863a SSD (mirrored, VM disks)
  • 2x 1.92TB SSD, 2x 14TB IronWolf and 2x 8TB Toshiba HDD (passed through to TrueNAS)

After adding a GPU the fans turned the server into a noise machine, so I run them with manual iDRAC fan control. Two YuanLey switches with 2.5GbE ports and 10G SFP+ uplinks connect it to the rest of the house, and a TerraMaster F2-220 running DSM holds the backups.

Network

pfSense runs as a VM and does routing, DHCP, DNS and firewall. There are no VLANs: the X540-T2 is split with SR-IOV and each VM gets its own virtual function, which took VM to VM traffic from 2.5gbps on a vSwitch to 14gbps.

HAProxy on pfSense is the reverse proxy for everything, with multiple domains on one public IP, Authelia in front of services without their own login and mTLS for a few subdomains. CrowdSec blocks the usual scanners and Pi-hole takes care of ads.

A WireGuard tunnel to an Oracle Cloud VPS gives me something offsite. The VPS runs a second domain controller, Uptime Kuma to check the lab from the outside, and the comment server for this blog.

Time comes from a USB GPS receiver passed through to a small VM running gpsd and chrony. Every other VM uses it as its NTP server, which keeps Kerberos and the logs in sync.

Identity

  • Windows Server 2022 as the Active Directory domain controller.
  • FreeIPA for Linux, with a cross-domain trust to AD so AD users can log in to the Linux VMs through SSSD.
  • A Dockerized Samba DC on the VPS as the secondary domain controller, replicating over WireGuard.
  • Authelia for SSO and OIDC in front of the web apps, like Outline.

Storage and Backups

TrueNAS runs as a VM with its disks passed through, and every pool is a ZFS mirror: one SSD pool and one HDD pool, shared over NFS (and iSCSI for my games).

Proxmox backs up every VM weekly to the TerraMaster over NFS, and the NAS syncs those backups encrypted to Google Drive. That gives me three copies with one of them offsite. Drive health is tracked with Scrutiny and scheduled SMART tests that send alerts to my phone.

Services

Three Debian VMs run around 100 Docker containers, managed with Portainer. Some of them:

  • Outline for documentation
  • Immich for photos
  • Nextcloud
  • The usual media stack
  • Gitea for my repos

The RTX 5060 is passed through to an Ubuntu VM that handles Plex transcoding, game streaming with Sunshine and a local LLM. LiteLLM sits in front of it and a few free cloud tiers so everything talks to one endpoint.

Monitoring and Automation

Wazuh is the SIEM for the VMs. Logs from every VM, container, pfSense, TrueNAS and Proxmox itself go to Grafana Loki through Alloy, with 30 days of retention.

VM provisioning, baseline hardening and maintenance are Ansible playbooks in a private Gitea repo, with all the secrets in Ansible Vault. A separate runner VM handles CI.
